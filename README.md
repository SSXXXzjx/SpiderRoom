# SpiderRoom

本地爬虫管理控制台。原生 HTML / CSS / JavaScript + Python，柔和深灰与低饱和绿界面，侧边栏可收缩，收缩状态自动记忆。已接入微博相册、小红书图集、谷歌图片和 Pinterest 图集，点击侧栏切换，各自独立配置、日志和运行记录。

## 功能

- 配置采集目标、下载并发、保存目录与 Cookie。
- 启动 / 停止采集，查看真实进度、实时日志和运行记录。
- 点击保存目录右侧的「选择目录」，打开 Windows 文件资源管理器样式的原生选择窗口，可通过地址栏、磁盘导航寻找目录；点击「选择文件夹」回填路径，再保存设置。
- 顶部「图片预览」展示保存目录及子文件夹中的图片，支持点击放大、原始尺寸和方向键切换。
- 默认保存原图，长边缩放可选、默认关闭。
- 输入底部裁剪像素，或打开图片拖动裁剪线，实时预览并显示像素数。

## 启动

1. 安装 Python 3.10+，在本项目根目录执行 `python -m pip install -r requirements.txt`。
2. 微博爬虫内置于 `crawlers/weibo/`，小红书 PC 采集接口及签名运行时内置于 `crawlers/xhs/`，`tools.json` 使用相对路径。
   小红书还需要 Node.js 22.15+（推荐 24 LTS），首次使用执行：

   ```bash
   cd crawlers/xhs
   npm install
   cd ../..
   ```
3. Windows 双击 `start.bat`，或执行：

   ```bash
   python server.py
   ```

4. 打开 `http://127.0.0.1:8765`，选择微博或小红书，填写目标和对应网站的登录 Cookie，开始采集。

使用独立 Python 环境时，在 `tools.json` 的 `python` 字段填写解释器路径。更换端口可执行 `python server.py --port 8888`。

## 谷歌图片

选择侧栏「谷歌图片」，填写关键词（每行一个）、保存目录和图片上限，无需 Cookie。支持实际最小宽高、搜索尺寸 / 类型 / 色彩、内容去重、并发下载、失败重试，以及平台已有的原图预览和图片处理。

默认使用已安装的 Chrome / Edge；高级设置可选择浏览器、填写 HTTP / SOCKS5 代理，搜索和下载均使用该代理。默认后台运行，不再自动打开网页等待验证；遇到访问限制会直接提示检查代理或更换节点。初次建议每个关键词只采集 2 张。当前环境已通过两张本地样本联调，真实 Google 请求曾被验证码拦截，尚未确认真实搜索下载成功。

使用说明和独立 CLI 见 [谷歌爬虫文档](crawlers/google_images/README.md)，三份参考的实现分析见 [技术分析](docs/google-images-analysis.md)。图标均通过 `resources/icons/` 相对路径加载。

## 图片处理

关闭缩放且裁剪为 0 时保留下载文件的原始尺寸、格式和字节。底部裁剪按输出像素计算：缩放关闭时按原图尺寸裁剪，开启时先缩放再裁剪。裁剪后的图片保存为 JPG。

左侧「图片工具 → 图片裁剪」在右侧独立工作区打开，支持底部裁剪、长边缩放和实时预览。点击「打开图片」选择本地图片，拖动裁剪线或输入像素，点击「保存图片」导出处理后的 JPG；原文件保持不变。

点击底部「保存到当前爬虫」按钮（显示对应工具名称）可将处理参数保存到当前爬虫，后续采集使用这些设置。切换爬虫分别保留处理参数草稿；采集运行时仍能独立处理本地图片。处理参数改变后会生成新的图片，保留之前的文件。

点击顶部「图片预览」查看已下载的图片，默认最新图片优先，每次加载 60 张，可继续加载更多。采集中预览当前任务的输出目录，其余时间预览「保存目录」输入框中的目录。点击「刷新」查看新下载的图片；点击缩略图可放大，通过「原始尺寸」查看细节，或使用左右方向键切换已加载的图片。

## 本地数据

配置和运行记录位于 `data/`，不提交到仓库。Cookie 点击「保存设置」后按爬虫保存在本机 data/ 下的配置文件中，重启、刷新及采集失败后仍会回填；清空输入框并保存可删除。未保存的 Cookie 在当前页面保留，点击采集不会清空。服务仅监听本机；终端按 Ctrl+C 停止服务和采集。

仓库只包含源码、界面图标、依赖声明和文档。下载图片、本机配置与 Cookie、运行记录、日志、临时文件、浏览器数据和已安装依赖均由 `.gitignore` 排除；`tools.json`、配置示例和签名运行时所需的 JSON 资源属于程序文件，需要保留。首次启动后会自动创建本机数据目录。

本仓库包含管理页面、运行服务，以及从本地 `weiboSpider` 整合的完整爬虫源码、依赖、文档和测试。原爬虫基于 [dataabc/weiboSpider](https://github.com/dataabc/weiboSpider)，原项目说明保留于 `crawlers/weibo/README.md`。小红书代码源自本地 `Spider_XHS`，仅整合 PC 图文采集所需模块；原项目目录保持原样。

## 小红书图集

- **笔记链接**：每行一个网页版完整笔记链接，支持 `/explore/…` 和 `/discovery/item/…`，保留 `xsec_token`。手机分享短链接请先在浏览器打开并复制完整地址。
- **用户主页**：每行一个 `https://www.xiaohongshu.com/user/profile/…`，按页采集该账号发布的图文笔记。
- **关键词**：每行一个词，可设每个关键词的笔记数和综合、最新、点赞、评论、收藏排序。
- 从已登录小红书网页版的网络请求头复制完整 Cookie，应包含 `a1` 和 `web_session`，点击「保存设置」后保留在本机。无需修改原项目 `.env`。
- 图片上限按每个笔记链接 / 主页 / 关键词分别计算，0 为不限；主页及搜索同时受高级设置中的页面上限约束。视频笔记自动跳过。
- 图片按用户和笔记分文件夹，支持重复跳过、并发下载、超时重试、长边缩放、底部裁剪和图片预览。更改图片处理参数会保留旧文件并生成新版本。
- 微博、小红书任务独立运行。切换工具保留页面尚未保存的草稿，刷新页面前请保存。

小红书适配器为 `xhs_worker.py`。依赖只安装图文采集必需部分，不要求原项目的视频处理、Excel、二维码或发布功能相关依赖。

## Pinterest 图集

选择侧栏「Pinterest 图集」，按分类填写 Pin、画板、分区、用户主页或 pin.it 短链接，也可选择「关键词搜索」每行输入一个词。支持粘贴搜索结果链接，各分类可同时填写，每个关键词独立计算图片上限。公开内容 Cookie 可留空，搜索或私密内容需要登录时再填写。支持原图优先、已知分辨率回退、有效图片数量上限、实际宽高过滤、内容去重、断点跳过，以及平台的目录选择、预览和图片处理。采集图片及视频封面，不下载视频。

内置适配器位于 `crawlers/pinterest/`，当前采集引擎已替换为本地 `pinterest-dl` 项目，源码和 Apache 2.0 许可内置于 `crawlers/pinterest/vendor/pinterest-dl/`；原项目目录保持原样。旧页面逻辑保留为异常恢复层，已有配置、Cookie 和图片目录继续使用。侧栏采用相对路径白色镂空图标 `resources/icons/Pinterest-display.png`。新引擎通过真实公开画板成功采集两张图片；长分页和私密画板未逐项实网验证。完整使用方式及接入细节见 [Pinterest 文档](crawlers/pinterest/README.md)。
