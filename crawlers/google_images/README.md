# Google 图片采集

从 SpiderRoom 左侧选择「谷歌图片」，填写关键词（每行一个），选择保存目录和每个关键词的图片上限即可开始，无需 Cookie。初次建议设为 2 张。

默认复用系统 Chrome，找不到时尝试 Edge；也可在高级设置指定浏览器。若使用 Playwright Chromium，先在平台根目录执行：

```powershell
python -m pip install -r requirements.txt
python -m playwright install chromium
```

已安装 Chrome / Edge 时通常无需第二条命令。代理填写在高级设置，例如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080`。此地址必须对应实际运行的代理服务；支持 HTTP 代理账号密码，不支持有认证的 SOCKS5。代理会随配置保存在本机 `data/google-config.json` 中。

支持搜索尺寸、类型、色彩、安全搜索和语言筛选，下载后用 Pillow 解码校验实际宽高。失败、尺寸不符或内容重复不会占用有效图片上限，会继续从后续候选补足；搜索结果不足时记录原因，保留已取得的图片。0 张表示不限制数量，仍受滚动上限约束。

默认保留原始文件格式、尺寸和字节。图片工具中的裁剪 / 缩放参数也适用于此入口，处理后输出 JPG（动画只处理首帧）。每个关键词有独立子目录，文件名为前缀加连续编号；`.image_index.json` 用于重跑跳过，`.sources.jsonl` 记录来源 URL、实际尺寸、内容 SHA256 和文件名。更改裁剪、缩放或最小宽高会重新判定输出。

点击停止会通知浏览器和下载器退出，已完成文件保留；超过 8 秒仍未退出时平台结束该任务的进程树。搜索和图片下载均使用配置的代理，默认后台运行。遇到验证或无法自动完成的隐私确认时，直接报告错误并终止任务，不自动打开验证窗口或等待手动操作。判断使用验证页路径及可见验证控件，不使用搜索结果中的“异常流量”等文字。

遇到访问限制时请检查代理服务和当前出口节点，更换可用节点后重新采集。配置代理不保证所有节点均能访问 Google。浏览器只在主动关闭后台运行或 CLI 使用 `--show-browser` 时显示。

也可以在平台根目录独立运行：

```powershell
python -m crawlers.google_images --keyword "mountain landscape" --count 2 --output "D:\Pictures\Google"
python -m crawlers.google_images --keyword "建筑摄影" --count 2 --min-width 1200 --proxy "http://127.0.0.1:7890" --show-browser
```

`--keyword` 可重复。`--config` 可加载平台导出的 JSON 配置，显式传入的 CLI 参数覆盖对应设置。

实现由浏览器发现、候选提取、并发下载、调度及平台 worker 组成。浏览器从页面元组、原图锚点、数据属性、搜索响应提取，缺少地址时尝试预览；不依赖固定类名或绝对 XPath。下载使用独立线程会话、流式读取、体积上限、重试、默认 TLS 校验、原子输出和内容去重。[参考项目分析](../../docs/google-images-analysis.md)记录了三份参考的技术与局限。

2026-10-15 验证：两张本地样本通过真实下载 / 校验 / 去重 / 重跑检查，平台浏览器检查通过。当前环境的真实 Google 请求触发验证码，因此真实搜索下载尚未验证成功。Google 页面变动、当前网络和来源站限制会影响实际采集，不能保证任意关键词达到指定数量。
